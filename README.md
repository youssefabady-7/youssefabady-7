## Featured projects

### [Study Buddy](https://github.com/youssefabady-7/Study-Buddy)

A team-built study assistant that turns uploaded course PDFs into a study workspace. It provides chat answers grounded in retrieved document passages, generated flashcards, multiple-choice quizzes, and optional spoken chat responses. The documented flow extracts and chunks PDF text, creates embeddings, and uses FAISS for retrieval before generating an answer.

**Stack:** Python, Streamlit, Groq (`openai/gpt-oss-120b`), Sentence Transformers (`all-MiniLM-L6-v2`), FAISS, pypdf, Kokoro TTS.

[Open the repository](https://github.com/youssefabady-7/Study-Buddy) · [Try the Study Buddy demo](https://stadybuddy77.streamlit.app/)
